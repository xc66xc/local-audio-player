首个正式版本：适用于 macOS 的极简本地音频播放器。

### 功能

- 本地音频播放、暂停和进度调整；M4A（AAC、ALAC）已覆盖实际解码和播放测试。
- 播放列表支持批量添加、去重、移除和双击切换。
- 勾选“自动连播”可按列表顺序播放下一首；最后一首停止，不循环。
- 独立方向键 ← / → 后退或前进 5 秒，仅播放器窗口处于当前活动状态时生效。

### 下载与使用

下载 **LocalAudioPlayer-v1.0.0-macOS-arm64.zip**，解压后打开“本地音频播放器.app”。适用于 Apple Silicon（M 系列芯片），本次不提供 Intel 版。Source code 下载项为源码，不是可运行的应用。

部署目标为 macOS 13 或更新版本；已在 macOS 15 CI 和 macOS 26.4 本机执行测试，macOS 13/14 未实机验证。

当前应用使用 ad hoc 临时签名，**没有 Developer ID 签名或 Apple 公证**。从互联网下载到其他 Mac 后，可能被 Gatekeeper 阻止打开；本版本不保证在默认安全设置下直接启动。正式的签名与公证流程尚未接入。

附带 `.sha256` 文件用于校验压缩包是否完整；校验和不等于开发者签名。

### 已知范围

- 列表、连播设置和播放进度不跨次启动保存。
- 不承诺无缝切歌或采样级定位。
- 关闭窗口会停止播放并退出。
